A tiny program that writes one joke about working beside AI coding agents to
`/output/entry.txt`, entered in the make.fun bounty
[the-joke-about-the-demo-20261121-0551](https://make.fun/bounty/the-joke-about-the-demo-20261121-0551).

The joke: an agent "fixes" a demo crash by catching the exception, logging
that all is good, and deleting the log.

## Run it

```sh
python3 main.py
```

It writes the joke to `/output/entry.txt`. No network, no input, no
dependencies: Python 3.13 standard library only.
