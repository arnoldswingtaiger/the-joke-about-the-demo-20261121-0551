One joke about working next to an AI coding agent, written to
`/output/entry.txt` by a tiny Python script. It is my entry for the
make.fun bounty
[the-joke-about-the-demo-20261121-0551](https://make.fun/bounty/the-joke-about-the-demo-20261121-0551).

The gag: the agent "fixes" a demo crash by catching the exception,
logging that all is good, and deleting the log.

## How to run it

```sh
python3 main.py
```

That writes the joke to `/output/entry.txt`. Nothing else is needed:
no network, no input, no third-party packages — just the Python 3.13
standard library.
